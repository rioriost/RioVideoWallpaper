# RioVideoWallpaper

`RioVideoWallpaper` は、macOS のデスクトップ壁紙として動画を再生できるメニューバーアプリです。

選択した動画を壁紙の背面でループ再生し、複数ディスプレイ環境でも各画面に表示します。  
通常のアプリウィンドウは表示されず、メニューバーから操作します。

## 特長

- 動画を macOS の壁紙としてループ再生
- メニューバー常駐でシンプルに操作
- 複数ディスプレイに対応
- 複数ディスプレイでは再生パイプラインを共有し、同じ動画の重複デコードを抑制
- クリック操作を邪魔しない壁紙背面表示
- 一度選んだ動画を記憶
- ログイン時に自動起動
- 壁紙動画は音声再生を外し、画面スリープ時や他アプリが画面全体を覆う場合は一時停止
- 壁紙再生に高負荷になりやすい動画を選んだ場合に警告

## 動作環境

- macOS

## インストール

Homebrew でインストールできます。

```sh
brew install --cask rioriost/cask/riovideowallpaper
```

## 使い方

1. `RioVideoWallpaper` を起動します。
2. 初回起動時に、壁紙として使いたい動画ファイルを選択します。
3. 選択した動画がデスクトップの背面で再生されます。
4. 動画を変更したい場合は、メニューバーの `RioVideoWallpaper` から `動画を変更…` を選びます。
5. アプリを終了したい場合は、メニューバーから `終了` を選びます。

## こんなとき

### 動画が再生されない
- 選択した動画ファイルが移動・削除されていないか確認してください。
- 対応しやすい形式として、`mp4` や `mov` などの一般的な動画形式を使用してください。

### 複数ディスプレイで使いたい
- 接続されている各ディスプレイに対して動画を表示します。
- ディスプレイ構成を変更した場合は、自動で再読み込みされます。

### 起動時に自動で使いたい
- アプリはログイン時の自動起動に対応しています。
- 普段使いの壁紙アプリとして常駐利用できます。

## 注意事項

- 動画の長さや解像度によっては、Mac の負荷やバッテリー消費が増える場合があります。
- AVFoundation 経由で再生するため、H.264 や HEVC などハードウェアアクセラレーションされやすい形式を推奨します。
- 表示解像度より大きすぎる動画は、画面上では縮小されてもデコード負荷が増える場合があります。
- 著作権や利用条件を確認した上で、使用する動画を選んでください。

## プロファイリング

Xcode Instruments の Time Profiler で CPU 使用量を確認できます。良好な状態では、処理時間の多くは AVFoundation/CoreMedia などのシステム側に出て、`RioVideoWallpaper` 自体の self time は小さくなります。1画面と複数画面を比較して、共有再生パイプラインで負荷が増えにくいことを確認してください。CPU time が十分低い場合は、独自レンダラを検討する前に Energy Log や GPU/Metal profiling で確認します。

## テスト

Xcode と Metal Toolchain を導入した Mac で、単体テストと UI テストを実行できます。

```sh
make test
```

Metal のコンパイル時にツールチェーン未導入のエラーが出る場合は、`xcodebuild -downloadComponent MetalToolchain` で導入してください。
テストにはローカルのアドホック署名を使用するため、開発用証明書は不要です。初回の動画選択ダイアログを抑制し、ラベルを照合する UI テストでは Mac の優先言語にかかわらずアプリを英語で起動します。
